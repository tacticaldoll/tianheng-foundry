# Tianheng Foundry - Identity

**Tagline:** Forge declared Rust architecture prose into tested Tianheng reactions.

Tianheng Foundry is an auxiliary, portable skill collection for Tianheng adopters. It is generative:
it may write Rust boundary and proof code. It is not legislative: it works only from intent the
project or user already declared, and every generated result remains a candidate for human review.

## Relationship To Tianheng

Tianheng owns the boundary DSL, observation engines, projections, and reactions. Foundry owns the
controlled transition from an adopter's prose claim to a reaction-proven candidate that uses those
public surfaces.

Foundry is not a Tianheng crate, observation dimension, policy library, or source of law. The
projects release independently and use neither submodules nor vendored repositories.

## Relationship To Fornax

Fornax is the structural precedent for portable skill packaging and progressive disclosure.
Foundry is not a Fornax package and does not inherit Fornax's read-only identity: its core workflow
performs guarded edits and verification.
