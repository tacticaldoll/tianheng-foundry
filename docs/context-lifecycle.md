# Governance Context Lifecycle

```text
ProseClaim
  -> ClassifiedClaim
  -> AdmittedIntent
  -> BoundaryCandidate
  -> VerifiedCandidate
  -> AcceptedLaw
  -> GeneratedProjection
  -> AgentChange
  -> Reaction
  -> Repair | Amendment | CapabilityPressure
```

## Formation

The formation loop turns declared intent into candidate law. Skill judgment belongs in
classification, observation admission, recipe selection, and controlled generation. Tests prove
teeth and precision. Human review alone accepts the candidate.

## Operation

The operation loop projects accepted Rust law into agent-readable context, lets work proceed, and
reacts to drift. Projection and evaluation are deterministic Tianheng responsibilities, not skill
judgment.

## Evolution

A violation normally directs repair toward the accepted reason. Changing the target, rule,
parameters, depth, severity, or reason is a deliberate amendment. A claim Tianheng cannot observe
becomes documented capability pressure, not a pretend boundary.

## Skill Admission

Name a new skill only when one lifecycle transition has an independent trigger, output, and failure
mode. Do not create a skill for deterministic projection or reaction, and do not split a single
transaction merely to produce a larger collection.
