# Gap Classification

A missing recipe in local memory is not a Tianheng capability gap.

## Classification

| Verdict | Evidence | Destination |
|---|---|---|
| `EXISTING_RECIPE` | Supported public boundary observes the contradicted fact | `forge-law` |
| `COMPATIBILITY_UNKNOWN` | Resolved version is unsupported or its surface was not inspected | Compatibility investigation |
| `NON_STRUCTURAL` | Claim governs process, judgment, history, or API explanation | Project prose |
| `CROSS_LANGUAGE` | Essential fact lies outside the Cargo workspace/Rust observation | Narrow or external governance |
| `TRUE_GAP` | Authorized Rust structural fact has a concrete source but no supported observer | Shape capability pressure |

## Search Discipline

Inspect:

- adopter manifests and lockfile;
- resolved Tianheng docs and public types;
- the current recipe routing index;
- relevant static, semantic, runtime, and composed boundaries; and
- declared non-observations of the nearest recipe.

Record search paths and exact version. Do not assume a newer release has or lacks the capability.

## Claim Test

State one sentence:

```text
At <target>, observation source <source> can reveal <fact>, whose presence contradicts <authority>.
```

If `<source>` cannot be named, the pressure is not ready. If the sentence needs non-Rust state,
classify or narrow it before continuing.
