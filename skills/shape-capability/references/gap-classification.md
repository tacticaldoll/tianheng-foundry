# Gap Classification

A missing recipe in local memory is not a Tianheng capability gap.

## Classification

| Verdict | Evidence | Destination |
|---|---|---|
| `EXISTING_RECIPE` | Supported public boundary observes the contradicted fact | `forge-law` |
| `COMPATIBILITY_UNKNOWN` | Resolved version is unsupported or its surface was not inspected | Compatibility investigation |
| `NON_STRUCTURAL` | Claim governs process, judgment, history, or API explanation | Project prose |
| `CROSS_LANGUAGE` | Essential fact lies outside the Cargo workspace/Rust observation | Narrow or external governance |
| `TRUE_GAP` | Authorized Rust structural fact has a concrete source but no supported observer | Shape the observation contract |

## Ownership

`TRUE_GAP` names a missing observation. It does not say whose it is, and from Tianheng `0.5.0` there
are two answers: an `Observer` outside the family can join a run, so the adopter is a possible owner
rather than only a petitioner.

| Owner | Evidence | Destination |
|---|---|---|
| `UPSTREAM` | The fact is a general property of Rust architecture that a dimension should hold, and another adopter would want the same reaction | Tianheng capability pressure |
| `ADOPTER` | The fact is this project's own convention — its naming, layout, or house rule — and a dimension holding it would be governing one project's taste | An adopter-owned `Observer` |

Ask which repository would be wrong if the reaction did not exist. If the answer is *every Rust
project adopting Tianheng*, it is upstream's. If the answer is *only this one*, it is the adopter's.

Two failure directions, and both are routing errors rather than honest calls:

- routing a general capability to the adopter, which leaves every other adopter to rediscover it and
  buries the evidence upstream needed;
- routing a house rule upstream, which asks a dimension to carry one project's taste as universal
  policy.

Ownership changes the destination and nothing else. The named source, the perimeter, the declared
bounds and both proofs are required of either. An adopter-owned observation is not a cheaper gap:
`Observer::bounds()` has no default body, so a participant that will not state what it does not see
cannot be written at all.

## Search Discipline

Inspect:

- adopter manifests and lockfile;
- resolved Tianheng docs and public types;
- the current recipe routing index;
- relevant static, semantic, runtime, and composed boundaries; and
- declared non-observations of the nearest recipe.

Record search paths and exact version. Do not assume a newer release has or lacks the capability.

## Claim Test

State one sentence:

```text
At <target>, observation source <source> can reveal <fact>, whose presence contradicts <authority>.
```

If `<source>` cannot be named, the pressure is not ready. If the sentence needs non-Rust state,
classify or narrow it before continuing.
