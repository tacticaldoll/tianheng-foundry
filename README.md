# Tianheng Foundry

Portable companion skills that turn declared architecture prose into tested Tianheng reactions
for Rust projects.

The collection does not supply architecture policy. It admits only project-declared constraints
that Tianheng can observe, writes candidate law, proves the reaction, and leaves acceptance to the
project's human review.

## Skills

- `forge-law` - materialize an observable prose constraint as a reaction-proven Tianheng law
  candidate.

## Status

Experimental. The initial compatibility target is Tianheng `0.3.x`.
